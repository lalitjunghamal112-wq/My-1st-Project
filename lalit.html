Reflective Report on my portfolio website project

Honestly, when I first started this module, I had no real idea how websites were actually built. I’d used websites every day, but coding one myself felt completely new and a bit overwhelming. At the start, even writing basic HTML felt confusing, especially trying to remember tags and how everything fits together. As I worked on my portfolio project, things slowly started to make more sense. One of the best moments was when I turned a plain HTML page into something that actually looked like a real website using CSS. That was a big confidence boost. I started experimenting with colours, layouts, and fonts, and it was interesting to see how small design choices could completely change the feel of the site. I decided to keep my portfolio simple and clean because I wanted it to be easy to use. I didn’t want too many colours or distractions, so I stuck to a basic colour scheme and readable fonts. I was inspired by modern portfolio websites that look minimal but still professional, and I tried to recreate that style in my own way. Not everything went smoothly though. Debugging was probably the most frustrating part. There were times when my code just didn’t work, and I had no idea why. Most of the time it turned out to be something small, like a missing bracket or a typo, which was annoying but also taught me to pay attention to detail. Using validation tools really helped me spot those mistakes. Looking back, my website improved a lot over time. It started off very basic, but by the end, it felt like a proper portfolio that I could actually show someone. Overall, this module helped me build confidence in coding and made me realise that web development is something you learn step by step through practice and mistakes.
